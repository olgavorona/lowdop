# Halloween Mazes with Denny

Generated A4 PDF printables for Harmless Apps website content.

- 6 friendly Halloween themes
- 3 difficulty levels per theme
- Color and printer-friendly black-and-white versions
- Individual worksheets are PDFs, with SVG files kept for web previews
- Includes plain, collect, shaped and avoid maze variants
- Footer includes `www.harmlessapp.com`
- `json/` files keep maze metadata and solution paths for future web pages
